Uma estrutura que se adapta

Organização simples para qualquer tela

Esta página demonstra como o CSS Grid pode distribuir as áreas de um site. Em telas grandes, o menu aparece ao lado do conteúdo. Em telas pequenas, o menu desaparece e o conteúdo ocupa toda a largura disponível.

01

Áreas bem definidas

A propriedade grid-template-areas nomeia e organiza cabeçalho, menu, conteúdo principal e rodapé.

02

Adaptação responsiva

Uma media query altera a estrutura do grid quando a largura da tela é de 768 px ou menos.

Dica: redimensione a janela do navegador para observar a mudança entre o layout de duas colunas e o layout de uma coluna.
